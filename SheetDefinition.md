- TIME
  - the time of the entry, may have three format
    - XX:YY for exact time
    - XX:YY-AA:BB for time range
    - DX | XX/XX | XXX for a day start entry
- CHINESE NAME
  - the chinese name of the entry
- ENGLISH NAME
  - the english name of the entry
- MEMO
  - memo of the entry
- GOOGLE MAP LINK
  - link to google map if the entry is a location
- SHOW
  - show in the trip tab or not, if it's TRUE and chinese name is not empty then it should be in the trip tab
- TICKET MEMO
  - ticket memo if the location need a ticket
TICKET LINK
  - ticket link if the location need a ticket
LATITUDE
  - gps latitude of the location
LONGTITUDE
  - gps longtitude of the location
PAGE LINK NAME
  - location site file name
